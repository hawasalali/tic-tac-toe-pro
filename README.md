Tic Tac Toe Pro is a desktop game developed in Python using Tkinter. The game includes score tracking, play statistics, winner detection, tie detection, color-coded moves, game reset, score reset, and a modern user-friendly interface.


Tic Tac Toe Pro

A professional Tic Tac Toe game created with Python and Tkinter.

Features:
- Two-player gameplay
- Winner and tie detection
- Red X and green O fields
- Score tracking system
- Play statistics tracking
- Current player display
- Reset game functionality
- Reset score functionality
- Responsive graphical user interface

Technologies:
- Python 3
- Tkinter
